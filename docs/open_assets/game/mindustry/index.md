__更新日志__：
> 
> 本次更新引入了新系统，用于向地图或服务器中添加任意内容（声音、音乐、图像、方块、物品等）。就功能而言，这非常接近 JSON 模组所能提供的能力，但无需任何手动下载。
> 任何包含资源的地图/存档，都必须通过游戏内界面导出才能正常工作；出于性能考虑，除非以这种方式导出，否则资源不会直接嵌入地图/存档文件中。
> 该系统可能存在较严重的 Bug，因此本版本之后预计会有热修复更新。
> 
> 1. 平衡性调整
> - _提高了铜传送带的速度（4.2 → 6.5 个/秒）_
> - _降低了连接点的建造时间（0.15 → 0.075 秒）_
> - _使质量驱动器的子弹根据时间缩放移动更快_
> - _对 Serpulo 科技树中的非必要需求进行了小幅修改（注：将小型热量传输机的建造所需资源中巨浪合金的数量从8个降为3个）_
> - _更新了许多 Serpulo 区域关卡_
> - _更新了区域关卡的难度值以反映实际难度_
> - _使研究优先选择玩家当前未在游玩的区域_
> 
> 2. 地图与界面功能优化
> - _添加了"类似 LOD"的系统，用于在拉远视角时隐藏各种细节（如电力激光等）_
> - _移除了摄像机缩放等级的取整_
> - _在沙盒模式中添加了传送至光标位置的快捷键_
> - _添加了"开发者选项"设置标签页_
> - _添加了查看性能统计的选项/快捷键_
> - 为系统文件选择器添加了多文件选择支持
> - 为字体添加了新图标
> - _添加了对内容描述中表情符号格式的支持_
> - 将 Steam 公开托管复选框移至暂停菜单，而非游戏设置
> - 使设置中的复选框样式略有改善
> - 将"显示敌人出生点"重命名为"隐藏敌人出生点"
> 
> 3. 系统规则与兼容性变更
> - 将专用服务器的规则配置移至独立文件
> - 调整了游戏启动时专用服务器的获取顺序，以防止不公平的 ping 解析
> - _添加了用于检测单位是否在飞行，以及检测 Erekir 方块热量的逻辑传感器_
> - 添加了用于播放音乐的逻辑指令和服务器远程方法（可来源于服务器资产/地图资产）
> - 添加了用于随机播放音乐的地图规则（`Rules#ambientMusic`、`Rules#darkMusic`）；目前这些值无法在地图编辑器中编辑
> - 为 JSON 模组/数据补丁添加了 `NoiseEffect`
> - 添加了通过读取指令读取处理器链接的功能
> - 在私人（仅好友）房间中禁用了"全局"Steam 恶意破坏者封禁列表
> - 修复了 JS 中默认方法不可覆盖的问题（归类于此，因涉及脚本兼容性）
> 
> 4. Bug 修复与性能优化
> - 优化了各种静态方块（如墙壁）的渲染
> - 改为在播放时加载声音，而非游戏启动时加载（节省约 150MB 内存）
> - 改进了服务器快照数据包的序列化性能
> - 改进了 `Call.label`（用于插件）的性能
> - 提高了世界连接流的传输速率
> - _修复了废弃方块有时仍会提供电力的问题_
> - 修复了复制逻辑块时，在特定条件下链接会被重命名的问题
> - _修复了在休闲难度下"零号地带"教程卡住的问题_
> - 修复了若干服务器崩溃/漏洞问题
> - _修复了清除星球研究后未正确重置花费的问题_
> - _修复了单位能力数据（如护盾）无法保存的问题_
> - 修复了电力节点断开连接导致电力网络图闪烁的问题
>
> 5. 其他
> - 桌面版的 Java 版本升级到17——你将无法再用 Java 8 启动游戏/服务器
> - 将 Android 最低 Java SDK 版本提高到 21（Android 5.0+）
